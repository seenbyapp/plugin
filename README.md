# AI search visibility by Seenby

AI search visibility tracking for Claude Code and Codex. The plugin adds the [Seenby](https://seenbyapp.com)
MCP server and a skill, so you can ask "where is my brand missing in AI answers?" and get the answer from
your Seenby data: brand mentions in AI answers from ChatGPT, Perplexity, Gemini, Google AI Mode and Google
AI Overviews, the competitors named instead and the pages each answer cites. Use it for AI visibility
tracking, LLM brand monitoring and generative engine optimization (GEO).

- MCP server: `https://seenbyapp.com/mcp` (OAuth; sign in to Seenby when asked)
- Skill: how to read Seenby reports and which tools use answers from your plan

Install in Claude Code:

```bash
/plugin marketplace add seenbyapp/plugin
/plugin install seenby@seenby
```

Reference: https://seenbyapp.com/developers/ · Privacy: https://seenbyapp.com/privacy/
